# 📊 PhonePe Transaction Dashboard (Excel)

## Overview

This project is an interactive Excel dashboard built to analyze PhonePe UPI transaction data using Pivot Tables, Pivot Charts, Slicers, and Excel dashboard techniques.

## Dashboard Preview

![Dashboard](dashboard.png)

## Features

- 📈 KPI Cards
- 📅 Daily Transaction Analysis
- 🕒 Hourly Transaction Analysis
- 🏦 Bank-wise Analysis
- 📱 UPI App Analysis
- 🌍 State-wise Analysis
- 🗺️ Heat Map
- 🍩 Donut Charts
- 🎛️ Interactive Slicers

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
- Map Charts
- Doughnut Charts

## Skills Demonstrated

- Data Cleaning
- Data Analysis
- Dashboard Design
- Data Visualization
- Business Intelligence
- Excel Reporting
